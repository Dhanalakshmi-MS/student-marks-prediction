# Student Marks Prediction Using Machine Learning

## Project Overview
This project uses Machine Learning to predict student marks based on the number of hours they study. It uses the Linear Regression algorithm to understand the relationship between study hours and academic performance.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Project Structure
```text
marks_prediction/
├── data/
│   └── student_scores.csv
├── scr/
│   └── train_model.py
├── README.md
├── requirements.txt
└── .gitignore
```

## Features
- Loads student performance data.
- Trains a Linear Regression model.
- Predicts marks based on study hours.
- Evaluates model performance.
- Displays a data visualization graph.

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python scr/train_model.py
```

Enter the number of study hours when prompted to get the predicted marks.

## Machine Learning Algorithm
Linear Regression
